# Alfred — Comprehensive feature backlog

This is an idea inventory, **not** a promise to implement everything. Mark items V1, V2 or Later as indicated; prioritize observed usefulness over feature count.

## Proactive intelligence
- **V1:** Morning/evening briefings, reminders, recurring schedules, quiet hours, duplicate prevention.
- **V2:** Event-change alerts, commitment follow-ups, weekly planning, priority suggestions, goal monitoring, escalation policies.
- **Later:** Complex multi-step conditional automations.

## Email and communication
- **V1:** Actionable-email triage, bounded inbox digest, thread summary, deadline extraction, source links.
- **V2:** Unanswered-thread tracking, follow-up suggestions, drafts awaiting approval, email-to-task conversion, writing-style preferences.
- **Later:** Attachment intelligence, inbox categorization/cleanup, approved cross-account summaries, external reply handling.

## Calendar and time
- **V1:** Next-day calendar, time-zone correctness, conflicts, RSVP visibility.
- **V2:** Meeting preparation, pre-meeting alerts, free-slot suggestions, focus-time suggestions, deadline planning, notes-to-actions.
- **Later:** Approved rescheduling and meeting attendance.

## Durable memory and tasks
- **V1:** Explicit preferences, conversation/project context, durable commitments, corrections, status transitions.
- **V2:** Memory consolidation, source citations, semantic search, expiration and relevance controls, decision history.
- **Later:** Knowledge graph and feedback-learned relevance.

## Research and monitoring
- **V2:** Site change detection, GitHub releases, technical digests, product availability, price monitoring, cited research, source comparison.
- **Later:** Delegated multi-step research with budget controls and review.

## Engineering and development
- **V2:** Repo progress, GitHub PR and issue digests, CI failure alerts, dependency advisories, release summaries, structured technical learning.
- **Later:** Sandboxed code-writing subagent, PR creation with approval, automated debugging experiments.

## Personal administration
- **V2:** Bill/renewal reminders, travel briefs, appointment preparation, delivery tracking, receipt extraction, document expiry, packing lists.
- **Later:** Financial integrations, booking/purchase assistance with explicit approvals.

## Interactions and companion experience
- **V1:** Telegram text commands, concise notifications, task status explanations.
- **V2:** Interactive approvals, voice-note transcription, PDF and screenshot interpretation, multilingual requests, progress updates.
- **Later:** Original character-led iOS/Android app, expressive animations, voice conversation and multimodal interface.

## Reliability, privacy and safety
- **V1:** Least-privilege adapters, synthetic fixtures, run history, idempotency, failure reporting, budget limits.
- **V2:** Approval engine, per-tool audit, model routing and evaluation, prompt-injection tests, recovery flow, permission revocation.
- **Later:** Durable workflows/queues, external-party delegated actions, stronger isolation for multi-user operation.

## Selection rubric
For each feature score: repeat-use value, trigger frequency, verifiability, data sensitivity, implementation cost and failure consequences. Ship one end-to-end flow before building an extensive integration catalog.
